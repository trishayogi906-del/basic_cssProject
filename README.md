# Amazon Clone

A simple **Amazon Clone website** created using **HTML and CSS**.  
This project is made for practicing frontend development and understanding how real e-commerce websites are structured.

## 🚀 Features

- Amazon-style navigation bar
- Search bar
- Product boxes
- Hero section
- Product categories
- Responsive layout
- Footer section
- Clean and simple UI

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📁 Project Structure

```text
Basic_cssProject/

├── index.html

```

## 🎯 Purpose of the Project

The main purpose of this project is to practice:

- HTML page structure
- CSS styling
- Flexbox
- Layout design
- Navigation bars
- Product cards
- Basic responsive design

## ▶️ How to Run

1. Clone the repository:

```bash
git clone git@github.com:trishayogi906-del/basic_cssProject.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! 🎉
